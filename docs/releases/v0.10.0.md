# zt 0.10.0 — Native Mac support

zt now officially supports **macOS 14 and later on Apple Silicon and Intel**. The native Cocoa/AppKit backend brings zt to the Mac without X11 or third-party runtime libraries.

## Get started on Mac

Download **`zt-aarch64-macos.zip`** for Apple Silicon or **`zt-x86_64-macos.zip`** for Intel, extract the archive, and open `zt.app`. Standalone `.bin` executables are also included.

Prefer building from source?

```sh
brew install zig@0.16
export PATH="$(brew --prefix zig@0.16)/bin:$PATH"
zig build -Doptimize=ReleaseFast
sh tools/package-macos.sh
open zig-out/zt.app
```

## Mac highlights

- Native Cocoa windows and menus, with `/bin/zsh` as the default login shell.
- Cmd+C / Cmd+V for copy and paste; Cmd+W / Cmd+Q for closing and quitting. Large pastes are preserved in full.
- Native input-method composition, inline preedit, and IME candidate positioning, with Japanese and emoji text support.
- Mouse selection, button-aware dragging, vertical and horizontal scrolling, and terminal mouse reporting.
- Resizing updates the terminal grid and PTY. Finder launches start at home; CLI launches preserve the current directory.
- Darwin PTY lifecycle fixes, correct Intel Objective-C struct returns, and responsive event handling during sustained output.
- Apple Silicon and Intel CI now exercise builds, real PTY I/O, Cocoa integration, and app signature verification.

## Linux and distribution

Linux framebuffer, X11, and Wayland support continues. This release includes x86_64 and aarch64 Linux executables for both X11 and Wayland, alongside the new Mac binaries and app bundles.

Mac bundles are ad hoc signed and **not notarized by Apple**. Physical IME candidate interaction and multiple-display behavior remain manual QA items; see the [macOS QA checklist](https://github.com/midasdf/zt/blob/v0.10.0/docs/macos-qa.md). Zig **0.16.0** is required for source builds.
